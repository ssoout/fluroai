# Переключение на SQLite

## Проблема

Backend все еще использует PostgreSQL, потому что переменная окружения `DATABASE_URL` установлена в системе или в сессии PowerShell.

## Решение

### Вариант 1: Использовать скрипт (рекомендуется)

**PowerShell:**
```powershell
.\start_backend_sqlite.ps1
```

**CMD:**
```cmd
start_backend_sqlite.bat
```

Скрипт автоматически удалит переменную `DATABASE_URL` и запустит backend с SQLite.

### Вариант 2: Вручную в PowerShell

1. **Удалите переменную DATABASE_URL:**
   ```powershell
   Remove-Item Env:DATABASE_URL
   ```

2. **Проверьте, что она удалена:**
   ```powershell
   echo $env:DATABASE_URL
   ```
   Должно быть пусто или ничего не выведется.

3. **Запустите backend:**
   ```powershell
   python -m uvicorn backend.app:app --reload
   ```

### Вариант 3: В новом терминале

1. **Закройте текущий терминал**
2. **Откройте новый терминал**
3. **НЕ устанавливайте DATABASE_URL**
4. **Запустите backend:**
   ```powershell
   python -m uvicorn backend.app:app --reload
   ```

## Проверка

При запуске должно быть:
```
[DB] Используется SQLite: sqlite:///...
[DB] ✓ Таблицы успешно созданы/проверены
```

**НЕ должно быть:**
```
[DB] Используется PostgreSQL: ...
```

## Если переменная установлена глобально

Если переменная `DATABASE_URL` установлена в системных переменных окружения Windows:

1. **Откройте "Переменные среды"** (через поиск Windows)
2. **Найдите `DATABASE_URL` в "Переменные среды пользователя"**
3. **Удалите ее** (или временно переименуйте)
4. **Перезапустите терминал**

Или просто используйте скрипт `start_backend_sqlite.ps1` - он удалит переменную для текущей сессии.
