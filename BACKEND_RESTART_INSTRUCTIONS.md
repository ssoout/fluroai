# Инструкция по перезапуску Backend

## Проблема
Маршрут `/patients/{patient_id}/studies` не зарегистрирован в запущенном backend, хотя он есть в коде.

## Решение

### Шаг 1: Остановите текущий backend
В терминале, где запущен backend, нажмите:
```
Ctrl + C
```

### Шаг 2: Перезапустите backend

**Вариант A - Используйте скрипт (рекомендуется):**
```powershell
.\restart_backend.ps1
```

**Вариант B - Вручную:**
```powershell
# Установите переменную окружения
$env:DATABASE_URL = "postgresql://postgres:275235@localhost:5432/fluroai"

# Запустите backend с автоматической перезагрузкой
python -m uvicorn backend.app:app --reload
```

### Шаг 3: Проверьте, что маршрут зарегистрирован

Откройте в браузере:
```
http://127.0.0.1:8000/docs
```

Найдите в списке endpoint:
```
GET /patients/{patient_id}/studies
```

Если он есть - всё работает! ✅

### Шаг 4: Проверьте логи

При запуске должно быть:
```
[DB] Используется PostgreSQL: localhost:5432/fluroai
[DB] ✓ Таблицы успешно созданы/проверены
```

### Шаг 5: Протестируйте endpoint

Запустите скрипт проверки:
```powershell
python test_endpoint.py
```

Должно показать:
```
✓ Маршрут /patients/{patient_id}/studies ЗАРЕГИСТРИРОВАН
✓ УСПЕХ! Найдено исследований: X
```

---

## Важно

⚠️ **Всегда используйте флаг `--reload`** при запуске backend в режиме разработки:
- Backend автоматически перезагрузится при изменении кода
- Не нужно вручную перезапускать после каждого изменения

⚠️ **Убедитесь, что переменная `DATABASE_URL` установлена** перед запуском:
- Иначе backend будет использовать SQLite вместо PostgreSQL
- Данные будут сохраняться в файл `backend/fluoro_backend.db`, а не в PostgreSQL

---

## Если проблема сохраняется

1. Проверьте, что файл `backend/app.py` сохранен
2. Убедитесь, что нет синтаксических ошибок:
   ```powershell
   python -c "import backend.app"
   ```
3. Проверьте, что используется правильная версия Python
4. Попробуйте остановить все процессы Python и запустить заново
