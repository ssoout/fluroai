# Финальные инструкции по запуску

## ✅ Переменная DATABASE_URL удалена

Теперь можно запустить backend с SQLite.

## Шаги:

### 1. Запустите backend:
```powershell
python -m uvicorn backend.app:app --reload
```

### 2. Проверьте логи при запуске:

**Должно быть:**
```
[DB] Используется SQLite: sqlite:///...
[DB] ✓ Таблицы успешно созданы/проверены
INFO:     Application startup complete.
```

**НЕ должно быть:**
```
[DB] Используется PostgreSQL: ...
```

### 3. Проверьте endpoint в браузере:

Откройте: `http://127.0.0.1:8000/docs`

Найдите в списке:
```
GET /patients/{patient_id}/studies
```

**Если его нет** - перезапустите backend еще раз.

**Если он есть** - попробуйте вызвать его с patient_id=11 (или любым существующим).

### 4. Протестируйте:
```powershell
python debug_studies.py
```

Должно показать:
```
✓ Маршрут для исследований пациента зарегистрирован
✓ Endpoint работает!
Найдено исследований: X
```

### 5. Проверьте во frontend:

1. Откройте frontend
2. Перейдите в "Пациенты"
3. Кликните на пациента
4. **Исследования должны отобразиться!**

## Если endpoint все еще не работает:

1. **Убедитесь, что backend полностью остановлен** (закройте терминал и откройте новый)
2. **Проверьте, что файл `backend/app.py` сохранен**
3. **Запустите backend заново**

## Важно:

- ✅ Используйте SQLite (не устанавливайте DATABASE_URL)
- ✅ Используйте флаг `--reload` для автоматической перезагрузки
- ✅ Проверяйте логи backend при создании исследований
