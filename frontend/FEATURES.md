## 🚀 Как протестировать:

### 1. Запуск приложения:
```bash
python main.py
```

### 2. Вход в систему:
- **Врач:** `doctor` / `123`
- **Администратор:** `admin` / `123`
- **Демо-режим:** кнопка "Демо-режим"

### 3. Тестирование функций:

#### Для врача:
1. **Загрузка снимка** → "Снимки" → "Загрузить снимок"
2. **Просмотр истории** → "История" → фильтры и детали
3. **Управление пациентами** → "Пациенты" → поиск и просмотр

#### Для администратора:
1. **Управление врачами** → "Врачи" → "Добавить врача"
2. **Просмотр отчетов** → "Отчеты" → экспорт и статистика
3. **Аналитика** → "Аналитика" → графики и диаграммы
